Default to using the `classNames` library when dealing with styling logic.

Default to using descriptive variable names over single letter names when appropriate.

Do not remove the TODO comments at the top of a file unless asked to.

When creating components with props, give them a named interface for props.

Default to using the `gap` utility class for uniform spacing, and fall back to using margin-top rule when spacing is irregular between siblings. Only use margin-bottom for appropriate cases that do not fit into either bucket.
